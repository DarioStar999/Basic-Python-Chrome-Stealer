<h2>Chrome Data Collector - Educational Use Only</h2>

<p>This script is designed for <strong>educational purposes</strong> only. It demonstrates how to locate and upload Chrome browser data files such as <code>Login Data</code> and <code>Local State</code> to a Dropbox account. It also collects and uploads the current machine's hostname and public IP address.</p>

<h3>⚠️ Important Notice ⚠️</h3>
<ul>
  <li>This script accesses potentially sensitive user data stored by Google Chrome.</li>
  <li>It uploads these files to a Dropbox account specified by an access token.</li>
  <li><strong>Use this script responsibly and only on machines where you have explicit permission.</strong></li>
  <li>Unauthorized access to or distribution of personal data is illegal and unethical.</li>
</ul>

<h3>Features:</h3>
<ul>
  <li>Retrieves Chrome's <code>Login Data</code> and <code>Local State</code> files.</li>
  <li>Fetches the current computer's hostname and public IP address.</li>
  <li>Uploads collected data securely to Dropbox.</li>
  <li>Deletes local copies after uploading for cleanup.</li>
</ul>

<p>This project is meant to help students understand how file access and cloud uploads can be automated in Python, <em>not</em> to be used for unauthorized data collection or privacy violations.</p>
